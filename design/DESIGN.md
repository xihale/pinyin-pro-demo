# 注音稿 · 设计说明

## 用户与任务

- 用户：中小学语文教师、对外汉语教师，偶尔是给讲义加注音的编辑。
- 任务：把中文放到纸上 → 逐字看到拼音落在汉字上方 → 复制到 Word / PPT 做讲义。
- 主动作：复制注音稿。次动作：改声调、改字号。
- 设备：桌面备课为主，手机查看与转发；320px 宽仍可读、可编辑、可复制。

## 选定方向：瑞士字体样张

用户指定瑞士极简，并明确要求删掉多余文字和组件。上一版“朱批笺”的纸纹、印章、宋体、暖白和四组参数全部撤掉；这一版把界面做成一张正在被编辑的国际主义字体样张：白纸、黑字、红色拼音、发丝线，没有卡片，没有独立输入区。

### 方向卡

| 字段 | 决定 |
| --- | --- |
| 北极星 | 一张可以直接改字的注音样张。拼音是纸上唯一的色彩事件，其他都退到线和小字。 |
| 调性 | 安静、精确、公共信息；疏；白纸与细线承担结构；庄重；中性。 |
| 标杆与取舍 | 拆了 PinyinMe 与 Toolshu。PinyinMe 的“逐字注音”成立，但把输入、参数、结果分成三段，参数占掉一整条；Toolshu 功能全，却被工具站导航、侧栏和广告淹没。保留逐字注音和复制到办公软件，换掉表单化流程与工具站外壳。 |
| 生成引擎 | 国际主义平面设计：无衬线、左对齐、严格的行列、发丝分隔线、大面积留白、一个红色。形象来自活字样张与版式校样，不来自“国风”道具。 |
| 首屏骨架 | 三带：顶栏（字号标识 + 复制）→ 占满视口的可编辑纸面 → 底栏（声调 / 字号 / 字数）。纸面直接是成品，不是空表单。 |
| 页面结构 | 单页工作区。没有导航、卡片网格、页脚营销、示例按钮、提示条。 |
| 各区块形式 | 汉字与红色拼音是主体；控件是小号文字 + 1px 边框；选中态是一条滑动的 2px 下划线；复制是唯一的实心黑块。 |
| 字体 | 汉字：Noto Sans CJK SC / PingFang SC 一脉的无衬线，400；拼音：同一无衬线，500，约汉字的 0.34；界面小字：13px。数字用等宽数字。 |
| 色彩 | 纸 `#ffffff`；墨 `#111111`；次级字 `#6f6f6f`；线 `#d9d9d9`；朱红 `#e1000f`，只给拼音、焦点线和复制成功。 |
| 主视觉 | 排版本身：红色逐字拼音压在黑色汉字上；唯一的重色块是复制按钮。没有配图。 |
| 图标 | 不用图标库。红色小方块、文字、下划线就是全部控件语法。 |
| 动效 | 首次进入：每行上移 6px 淡入，间隔 45ms，只播一次。切换声调/字号：选中下划线 180ms 滑到新位置。复制成功：按钮 240ms 轻微落定并变红，文案变“已复制”。全部尊重 `prefers-reduced-motion`。 |
| 结构性突破 | 没有输入框，也没有“注音”按钮：页面就是编辑器，输入即注音。没有卡片套卡片：整站收在一列居中的纸面里，桌面 960px 封顶、两侧发丝线收边，不铺满视口。 |
| 记忆点 | 红拼音逐字悬在字上，落墨时比汉字慢半拍；底栏像一把尺子；清空后只剩一句“点这里输入中文”。 |
| 放弃什么 | 暗色工具站、卡片套卡片、纸纹与印章、宋体、暖白、四组参数、toast 提示条、示例/清空按钮、页脚技术署名、第二个复制入口（只复制拼音）。 |

### 差异检验

- 与 PinyinMe 并排：骨架（单张可编辑样张 vs 输入→参数→结果三段）、字体（无衬线样张 vs 无衬线工具面板）、色彩（白纸红拼音 vs 暗色面板）、交互（页面即编辑器 vs 先按按钮）四项全不同。
- 与 Toolshu 并排：没有导航、面包屑、侧栏、推荐位和广告；结果区就是整页。
- 保留基线：逐字注音、复制到 Word/PPT；用户不用重新学。
- 至少一处打破品类套路：取消输入框与转换按钮，直接在注音结果上改字。
- 盲看：纯白、黑字、红拼音、发丝线，能说出“像一张瑞士排版的注音样张”，而不是“又一个在线工具”。

## 可见即所得

- 版心：桌面把整站收成一列居中的纸面，`max-width: 960px` 居中；视口更宽时两侧补 1px 发丝线收边，页头/页脚的横线只落在这一列内，不再拉满全屏。960px 及以下自然铺满、无侧线；打印时取消限宽与侧线，回到满页 A4。
- 纸面是 `contenteditable`：拼音用标准 `<ruby>/<rt>` 逐字标注，语义化、可选中、屏幕阅读器可读；`rt` 关闭 `pointer-events` 与 `user-select`，光标不会落进拼音。
- 中英文混排按基线对齐：行内用 `align-items: baseline`，而不是顶边或底边对齐。汉字格顶上是拼音带、英文格没有，按顶边对齐会把英文抬到汉字上方半行；按基线对齐后 “claude” 与 “啊” 落在同一条基线上，英文也不会因为多出一条拼音带而换行错位。
- 光标永不进拼音：`↑`/`↓` 由脚本按行移动（列位置保持不变），不交给浏览器的行内垂直定位；另有一条选区守卫——任何途径把光标放进了 `<rt>`，立刻把它移到那颗汉字之后，所以不会出现“在拼音里打字”的状态。
- 输入、中文输入法合成、粘贴、回车后重新渲染，并按纯文本偏移恢复光标。正文的插入与删除（`beforeinput` 的 `insertText` / `delete*`）一律 `preventDefault`，改为在 `state.text` 上算好新文本再重渲染，浏览器不直接改 DOM——否则跨 `ruby` 的替换会把 `<rt>` 里的拼音一起搬进正文（出现过 “zshā” 这种字）。剪切仍交给浏览器，好让系统剪贴板拿到内容。
- 光标偏移由“纸面起点到光标点”的 Range 统计，逐行去掉 `rt` 后再拼 `\n`。这样全选（锚点落在纸面元素上）、行首行尾、空行都能映射回纯文本偏移；早前只按单个 `.line` 计算，全选会塌缩成同一个偏移，导致全选后打字不替换。
- 标点吸附在前一个字（后引号、句号等）或后一个字（前引号、左括号等）上，换行时不会把标点甩到行首。
- 撤销/重做：`Ctrl/⌘+Z`、`Shift+Ctrl/⌘+Z`、`Ctrl+Y`，700ms 内的连续输入合并为一步。
- 空状态：纸面只有一句灰色占位，复制按钮禁用；没有示例按钮。
- 复制「注音稿」（主按钮）：双行段落式——每行一行红色拼音 + 一行黑色汉字，居中；Word、PPT、微信通吃，PPT 不会再被表格化破坏。
- 「Word 注音版」下载 `.docx`：原生 `w:ruby` 拼音指南（`rubyAlign=center`、显式字号/颜色/字体），Word/WPS 打开即逐字居中对齐、可再编辑。HTML 剪贴板无法携带 Word 的注音对齐属性（`w:rubyAlign`），Word 只能按"自动"猜——短音节左对齐、长音节居中，正是此前对不齐的根因。
- 选中文字 Ctrl+C：与主按钮同一格式（仅所选行）；纯文本保持所选原字，不带拼音。`Ctrl/⌘+A` 只选中纸面（不带上页头页脚）；选区跨越纸面边界时裁剪到纸面内容，避免浏览器把 `::selection` 高亮连同整页样式烤进剪贴板。
- 选中态是**纯文字变朱红**（`::selection` 无底色）：底色块会被浏览器连同高亮一起写进剪贴板，且行高大小的块会与相邻行互相压叠；只用颜色，既无块也无交叠。
- 旧浏览器回退到隐藏节点 + `execCommand`；失败时选中纸面文字并提示手动复制。
- 字号：小 38 / 中 48 / 大 60px，手机整体 ×0.8；复制到 Word 分别为 14 / 17 / 21pt 汉字、8 / 8 / 9pt 拼音。

## 动效与状态

- 复制：按下位移 1px；成功后按钮变红、文案“已复制”、240ms 缩放落定，1.6s 后恢复。
- 声调/字号：下划线滑块 180ms 平移，选项文字同时变黑加粗。
- 首次进入：每行上移 6px 淡入，行间隔 45ms；红色拼音比汉字晚 90ms 再淡入，形成“拼音落上去”的两拍，总时长不到 700ms。重新渲染、切换设置不重播。
- 空状态、数字声调、复制成功、复制失败、长文换行、320px、200% 重排、打印、输入法合成、撤销/重做、正文中间插入均已实测。

## 独立评审

- 第 1 轮（新界面整版，10 分制）：**8 / 10**。方向成立、主流程与异常状态齐全；扣分在两个可见问题（“只复制拼音”与主动作并列、语义不清；手机端两个设置组没有文字标签）和两处精致度（选中下划线与线框底边相交处发闷；拼音层可以更有印刷细节）。
- 已按评审修正：删掉“只复制拼音”这个第二复制入口（连带代码与样式），头部只剩主动作；选中下划线改为与分组底边齐平；入场加入“拼音晚半拍落上”的第二拍。
- 保留但有理由：手机端隐藏“声调 / 字号”标签，因为两组取值（符号/数字/无、小/中/大）本身自解释，而用户明确要求减少文字；桌面端保留标签。
- 未独立验证：粘贴到 Word / PPT 后的最终效果无法在浏览器里复现；已通过剪贴板 `text/html` 读回确认写入的是“拼音 div + 汉字 div”的表格与字号，Word 端需人工确认一次。

## 验收重点

- 每个汉字的拼音落在该字正上方，不连成一条、不压邻字；标点换行不落到行首。
- 48px 正文与 16px 拼音在 1440×900、390×844、320px 宽可读；放大后不靠缩小字号装下。
- 纸面点击即可输入；输入法、粘贴、回车、撤销/重做、光标位置正确。
- 复制成功后从剪贴板读回：富文本为表格（拼音 + 汉字、字号与颜色），纯文本保留两行与标点；失败不清空内容。
- 声调、字号即时生效，复制尺寸随字号变化。
- 打印只留纸面，页边距 18mm；`prefers-reduced-motion` 下内容直接呈现。

## 技术

- Astro 7 静态站点，单页；无 React、无客户端路由、无 CSS 框架。编辑器用原生 TypeScript 写在 `src/scripts/editor.ts`。
- `pinyin-pro` 在构建时服务端渲染首屏，在浏览器里负责交互后的注音。
- 依赖：Astro 7.4.1、pinyin-pro 3.29.5、TypeScript 5.9.3（`@astrojs/check` 当前支持到 5/6，未用 7）。
- 部署：GitHub Pages，`bun run build` 输出 `dist/`。
